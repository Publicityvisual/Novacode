Why Novacode?

⚡

Fast CLI

Initialize projects, generate code, run builds and tests from your terminal in seconds.

🤖

Smart TUI

Interactive terminal UI inspired by the best developer tools. Switch models, manage agents, and keep context.

🧩

Agents & Plugins

Create custom agents, extend behavior with plugins, and reuse sessions across projects.

🔒

Independent & Private

Total autonomy and freedom. Your workflow, your keys, your rules.

📊

Session History

Export, import, search, and resume past sessions. Built-in SQLite-backed history.

🛠️

Dev Tooling

Worktrees, PR management, MCP-style extensibility, and macOS app integration.

Get Started

macOS / Linux

git clone https://github.com/your-org/novacode.git
cd novacode
python3 -m venv .venv
source .venv/bin/activate
python3 novacode.py --help

Windows

git clone https://github.com/your-org/novacode.git
cd novacode
python -m venv .venv
.venv\Scripts\activate
python novacode.py --help

Interactive TUI

Start Novacode in interactive mode with a familiar terminal-first experience.

novacode tui
novacode tui --model local
novacode run "Create a REST API with FastAPI"
