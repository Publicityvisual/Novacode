ชุดโครงการชุมชนที่สร้างขึ้นบน NovaCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ NovaCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-novacode](https://github.com/awesome-novacode/awesome-novacode) และ [novacode.cafe](https://novacode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน

---
