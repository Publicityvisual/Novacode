Una colección de proyectos comunitarios construidos en NovaCode.

:::note
¿Quieres agregar tu proyecto relacionado con NovaCode a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-novacode](https://github.com/awesome-novacode/awesome-novacode) y [novacode.cafe](https://novacode.cafe), una comunidad que agrega el ecosistema y la comunidad.
