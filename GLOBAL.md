# NEXUS GLOBAL - Modelos en Todo macOS

## 🚀 Acceso Global

### Terminal
```bash
# Comandos principales
nx muse "Analiza imagen"
nx muse-ts "Crea hook React"
nx auto "Implementa API Python"

# Accesos rápidos
nx-quick ts "Crea componente"
nx-quick py "API FastAPI"
nx-quick db "Schema PostgreSQL"

# Modos
nx-offline check
nx-hybrid auto "prompt"
nx-conscious "Ayúdame a aprender"
nx-memory stats
```

### Variables de Entorno
```bash
NX_DEFAULT_MODEL=nexus-think:latest
NX_OFFLINE_MODEL=muse-conscious:latest
NX_CODE_MODEL=muse-code-offline:latest
NX_VISION_MODEL=nexus-vision:latest
NX_FAST_MODEL=nexus-fast:latest
```

### Apps de macOS
- **NEXUS**: Chat general multimodal
- **NEXUS Code**: Programación offline
- **NEXUS Vision**: Análisis visual

### Servicios del Sistema
- **NEXUS Quick Ask**: Servicio de consulta rápida
- **NEXUS Quick Selector**: Selección automática de modelo

## 📦 En Todos Lados

| Lugar | Acceso | Comando/App |
|-------|--------|-------------|
| Terminal | Global | `nx`, `nx-quick`, `nx-selector` |
| Apps | Servicios | NEXUS.app, NEXUS Code.app, NEXUS Vision.app |
| Shell | Aliases | `nx-run`, `nx-chat`, `nx-status` |
| Variables | PATH | `~/.local/bin` en PATH |
| Automático | Startup | Ollama inicia con la shell |

## ⚡ Inicio Rápido

```bash
# En cualquier terminal
nx "Hola mundo"

# Con tipo específico
nx muse-ts "Crea hook TypeScript"

# Auto selección
nx-selector "Implementa API Rust"

# Estado del sistema
nx-status
```
